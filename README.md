# Hippo Burgers — Restaurant Front End

A polished, responsive front-end redesign for Hippo Burgers, based on the live brand and locations.

## Included interactions

- Responsive navigation and mobile layout
- Menu category filtering for burgers, chicken, sides, and shakes
- Add-to-basket drawer with live subtotal
- Reservation/location modal
- Animated cards, hover states, and a responsive locations section

Open `index.html` in a browser to preview it.
